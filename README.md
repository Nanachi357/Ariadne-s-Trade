# Ariadne's Trade

Ariadne's Trade is a historical learning project exploring reactive market-data services with Spring Boot.

Implemented functionality:

- REST endpoints for public Deribit instrument data.
- Reactive storage and queries for trade records.
- PostgreSQL persistence through R2DBC.
- Redis-backed caching for instrument data.

Main technologies: Java 22, Spring Boot, Project Reactor, R2DBC, PostgreSQL, and Redis.

Exchange authentication and order execution are not implemented. The project is not actively maintained.
